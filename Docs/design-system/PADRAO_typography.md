# Padrão — Tipografia

## Famílias

| Papel | Stack |
|-------|--------|
| UI | `"Segoe UI", "Cascadia Mono", ui-sans-serif, sans-serif` |
| LCD / números | `"Cascadia Code", "JetBrains Mono", Consolas, ui-monospace, monospace` |

## Escala

| Elemento | Tamanho | Cor | Observação |
|----------|---------|-----|------------|
| Nameplate marca | 11px, letter-spacing 3px | `--text` | Uppercase, negrito |
| Nameplate subtítulo | 11px, letter-spacing 2px | `--text-dim` | Uppercase |
| Contador | 24–26px | `--amber` | Monospace + glow suave |
| Labels de campo | 10px, letter-spacing 1.5px | `--text-dim` | Uppercase |
| Segmented / tabs | 10–10.5px | dim / amber ativo | Uppercase, weight 600–700 |
| Status / hotkey | 11px | `--text-dim` (amber quando ativo) | — |
| Erro | 10px | `--danger` (`#cf5240`) | — |
