# Versão da linguagem

| Campo | Valor |
|-------|--------|
| Linguagem | Python |
| Versão do projeto | **3.12** |
| Fonte | Plano Clickr (`clickr_autoclicker_python`) — decisão travada do projeto |
| Plataforma | Windows 10/11, macOS, Linux (X11) |

## Aderência

Todo código do repositório deve usar apenas recursos disponíveis em Python 3.12.
Não utilizar sintaxe exclusiva de versões posteriores.

## Ambiente local

A versão instalada na máquina do desenvolvedor pode diferir; a fonte de verdade do projeto é **3.12**, não o interpretador detectado no PATH.
